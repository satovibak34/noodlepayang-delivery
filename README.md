# 🍜 Noodle Pa Yang Delivery (ก๋วยเตี๋ยวป่ายาง@บ่อแสน)

เว็บแอปพลิเคชันสำหรับสั่งก๋วยเตี๋ยวเดลิเวอรี่ รองรับการใช้งานผ่านมือถือและคอมพิวเตอร์

## 🌟 คุณสมบัติ (Features)
- เลือกรายการเมนูก๋วยเตี๋ยวและเครื่องดื่ม
- ระบบคำนวณราคาสินค้าในตะกร้าอัตโนมัติ
- กรอกชื่อ เบอร์โทรศัพท์ และที่อยู่จัดส่ง
- สั่งซื้อและส่งออเดอร์ตรงเข้า LINE / Telegram ของร้าน

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- HTML5 / CSS3
- JavaScript (Vanilla JS)
- GitHub Pages (Hosting)
